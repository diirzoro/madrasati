# Madrasati Details Template Pack v2

This pack is a DIRECT visual and asset reference for the Detail/Profile pages only.

## Templates
- institution-detail-template.html — Institution Detail/Profile for private schools, government schools, institutes, colleges and universities.
- teacher-profile-template.html — Teacher Profile.

## Assets
The `assets/` directory contains ten local image assets:
- school-private-1.svg
- school-private-2.svg
- college-1.svg
- college-2.svg
- institute-1.svg
- institute-2.svg
- school-government-1.svg
- school-government-2.svg
- teacher-1.svg
- teacher-2.svg

They are local visual placeholders/reference assets so the agent does not need to search the internet for images. Replace them with real database/API media when the application has real media, without inventing institution data.

## Icons
`icon-reference.html` contains the large colorful icon direction. Use the project's existing icon system where available, but match the reference scale: icons should be large, clear, colorful and visually prominent.

## Scope
Do NOT redesign:
- Dashboard
- Landing page
- Institution listing pages/cards
- Sidebar/navigation
- Global theme

Only improve Detail/Profile presentation and bind it to the existing API/database.

Do not create a second database, mock backend, or duplicate business logic.
