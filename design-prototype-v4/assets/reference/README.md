# Generic reference media (fallback ONLY)

These are clearly-generic placeholders. They are used **only** when an entity has
no media of its own, and they are **never** presented as a real photo of a named
institution or teacher. They must never be assigned to a named entity in place of
its real media.

Priority is always: entity media (DB/API) -> mapped project media -> entity upload
root -> this generic fallback.
